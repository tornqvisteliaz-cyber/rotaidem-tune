Rotaidem Tune Companion Package

This folder was placed by the Rotaidem Tune installer.

Rotaidem Tune is an **external** companion application. It does not load inside the simulator.
The actual program is installed at:
%LOCALAPPDATA%\Rotaidem\Tune\RotaidemTune.exe

Launch it from the Start Menu or desktop shortcut while Microsoft Flight Simulator 2024 is running.
It connects via the documented SimConnect interface and plays additional audio layers externally.

This Community folder entry exists only as a convenience marker. You can delete this folder without affecting the application.
