Rotaidem Tune

This Community folder entry is a marker for the external Rotaidem Tune application.

The actual program is a Windows executable that runs outside the simulator and connects via SimConnect.

Install location (after running the installer):
%LOCALAPPDATA%\Rotaidem\Tune\RotaidemTune.exe

Or run RotaidemTune.exe directly from the folder where you built it.

To hear the airflow layer:
1. Make sure assets/audio/airflow-wind.wav is next to the .exe (or in an assets/audio subfolder).
2. Launch RotaidemTune.exe while MSFS 2024 is running (or it will use simulated telemetry).
3. A console window will show indicated airspeed and the current airflow gain.

You can delete this Community folder without affecting the application.
